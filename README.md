Задание №2. Негативное изображение
Условие задачи
Негативное изображение — это инвертированная версия оригинала, где светлые участки становятся тёмными, а тёмные — светлыми. В цифровом представлении это означает замену:
- 0 (чёрный) → 1 (белый)
- 1 (белый) → 0 (чёрный). Dва подхода для проверки строки на палиндромность:
1. Обычный способ
2. Рекурсивный способ
